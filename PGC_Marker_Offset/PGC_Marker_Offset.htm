Marker Offset Copy

Copies the selected vectors onto a "PGC Marker Path" layer, shifted so a marker or pen mounted beside the spindle draws them in the right place.

Enter where the marker sits relative to the spindle (work coordinates). Example: Y = -58 means the marker is 58 toward -Y from the spindle, so the copy is shifted +58 in Y.
